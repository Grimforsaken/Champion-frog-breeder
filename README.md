# Champion Frog Breeder

A first-person Android frog catching, breeding, genetics, contest, and exploration game.

## Core loop

Explore one habitat per in-game day, search during Day / Evening / Night, catch frogs and bugs, return home, feed and grow frogs, breed them, sell extras to the pet shop, buy better field and home equipment, enter contests, and unlock new habitats.

## Opening progression

- Start at a backyard puddle.
- Start with no net; the player catches by hand.
- Frog carrying case holds 6 frogs.
- The starter breeding tank supports 2 adult frogs.
- Each time of day ends after 3 successful captures, or the player can skip forward manually.
- Failed capture attempts do not consume one of the 3 captures.
- Backyard Puddle bugs: cricket (evening/night) and worm (day/evening).
- An early blacklight flashlight helps locate fluorescent bugs during evening/night and later fluorescent frogs.
- The Pond unlocks shortly afterward and introduces new wildlife, including bullfrogs.

## Genetics

Frog appearance and performance are data-driven and inherited. See `docs/GENETICS.md` for the base color-number system and breeding rules.
